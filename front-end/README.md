# 📘 Projeto Multiplataforma unifor

## Plataforma de doações

Este é o front-end da plataforma de doações, onde doadores, ONGs e voluntários podem visualizar e gerenciar doações, eventos e outras atividades.

## Requisitos

- Node.js instalado
- Gerenciador de pacotes npm ou yarn

## Instalação

1. Clone este repositório:

```sh
git clone https://github.com/JonasTiago/proj-multiplataf-unifor.git
```

2. Acesse a pasta do projeto:

```sh
cd proj-multiplataf-unifor
```

3. Instale as dependências:

```sh
npm install
```

ou

```sh
yarn install
```

## Como Executar

Para rodar o projeto em ambiente de desenvolvimento:

- No navegador

1. Navegue até a pasta `/src`.
2. Abra o arquivo `index.html` com um navegador de sua preferência.

- No terminal

```sh
npm install -g http-server
http-server ./src
```

## Funcionamento

Na plataforma, é possível:

Cadastrar nova doação

Visualizar doações disponíveis

Acompanhar eventos futuros

Ver status de doações já realizadas

Ver detalhes de cada doação e evento

Exemplos de tela:
Painel inicial com resumo das últimas atividades

Menu lateral com opções de navegação

Botão “Ver Detalhes” para mais informações
